# Data folder

This directory is part of the repository layout:

| Folder | Purpose |
| ------ | ------- |
| `input/` | Localization CSV files |
| `metadata/` | Excel metadata (`dSTORM Data_Input.xlsx` or your own workbook) |
| `output/` | Pipeline ZIP archives and summary CSVs (created when you run the pipeline) |
| `temp/` | Scratch files during processing (created when you run the pipeline) |

For the demo, download `examples.zip`, extract the inner `examples/` folder, then move the three CSVs into `input/` and `dSTORM Data_Input.xlsx` into `metadata/` — see [README §3 Demo](../README.md#3-demo).
